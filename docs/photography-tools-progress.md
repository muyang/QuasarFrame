# 摄影地理工具实施进度

更新：2026-09-29。按“计算可信 → 计划可执行 → 专业分析”推进。

## 已落地

### 第一层：计算与展示

- 地点详情可选择拍摄日期和分钟级时间。现有中国地点统一按 Asia/Shanghai 计算和展示，不依赖用户电脑时区。
- 晨间黄金时段采用日出至太阳高度 +6°，晚间采用 +6° 至日落；蓝调采用太阳高度 −8° 至 −4°。均为理论地平线下的约定，未考虑现场遮挡。
- 日照图按全天 10 分钟间隔计算真实太阳高度，游标与相机光线跟随所选时间。
- 修正 SunCalc 2 已返回角度值和正北顺时针方位的适配，移除旧版弧度转换与方位偏移。
- 传感器提供全画幅、APS-C、M4/3；支持横竖拍和自定义实际焦距。分别展示水平/垂直视场和等效焦距，并纠正三维预览的垂直 FOV。
- 示意地形明确标注；移除伪随机天气评分/成功概率；发现页改为目录精选。
- 附近页明确显示直线距离，移除由直线距离推算的驾车时间；修复手动选城市与异步定位结果的覆盖竞争。
- 现有地点标记为待核验资料，坐标体系未注明，日照暂按 WGS84 近似；Unsplash 图片不再声称为地点实拍。
- 三维预览按参数变化/尺寸变化渲染，取消持续动画，卸载时释放几何体、材质与渲染器。

### 第二层：拍摄计划基础

- 地点详情增加拍摄计划，记录日期时间、镜头、传感器、方向、机位坐标、预计行程、器材准备时间及主体/路线/备选备注。
- 可填写自己的 GPS 坐标。未填写时使用目录示意坐标，来源随计划保留。
- 行程时间由用户提供，计算可跨日的建议出发时刻；未知行程不生成虚假估计。
- 支持本浏览器保存/读取（最多 50 份），JSON 导出与 GPX 点位导出。GPX 不包含计算路线，且说明坐标未经核验。
- 保存与读取均校验结构；存储受限或损坏会显示失败，不能假报保存成功。

### 第三层：方向对齐基础

- 以机位控制的方位和仰角作为目标方向，搜索当天太阳/月亮中心处于角度容差内的时段。
- 采用一分钟采样，展示开始/结束、最佳采样时刻、角距，以及计算时的参数快照；调整参数后需重新计算。
- 仅搜索理论地平线以上的天体位置。尚不判断主体轮廓、山脊遮挡或现场可见性，亚分钟精度不作保证。

## 接下来的推进顺序与验收

1. **先核验一个真实地点**：补齐地点、机位和主体的独立坐标、坐标体系、朝向、精度、来源及核验时间。用现场照片和已知日出方向验收方位叠加，保留误差记录。相框选型尚未确定时，优先完善网页工具与设备无关的计划模型。
2. **完成一次可执行拍摄计划**：接入选定的天气和路网服务，保存预报发布时间、有效时间及来源；分别展示驾车、步行和器材准备时间。验收应覆盖服务不可用、预报过期、道路不可达与跨日出发，未知项继续显示未知。再扩展跨设备计划同步。
3. **在同一地点验证专业分析**：引入有许可和精度说明的 DEM，生成机位地平线轮廓，并校验水平/高程基准。对照现场日月出现时刻测量误差，再推进多日期反查与银河规划。摄像头可用于观测反馈，但必须先明确其地点、朝向、采集时间与使用范围。

摄像头分发授权和画面更新延迟仍为待讨论项，不能据此确定缓存时长、对外分享或相框推送策略。应在授权边界与延迟目标确定后，另行验收采集时间展示、过期提示、断流降级及设备适配。

## 验证与运行

计算回归测试位于 `tests/photography.test.ts`，覆盖地点时间/跨日、晨晚事件与极昼、视场/裁切、景深单位、出发时间、非法输入、GPX 转义及日月方向角距/对齐搜索。

在现代 Node 环境中运行：

```sh
node --import tsx --test tests/photography.test.ts
node node_modules/typescript/lib/tsc.js --noEmit --incremental false
```

测试运行时使用项目已有的 tsx。开发服务的主进程与子进程必须都使用现代 Node；仅给主进程指定绝对路径、但 PATH 仍指向旧 Node，会导致 Turbopack 的 CSS 子进程失败。

- 10 项计算回归测试在 `TZ=Asia/Shanghai` 和 `TZ=America/Los_Angeles` 均通过。

- 初次构建暴露订单路由 `_nowTs` 非法导出及发现页缺少 Suspense 边界。后续启动测试中移除未使用的辅助导出、补齐边界，全量类型检查和 webpack 生产构建均通过。
- 生产预览已启动，主要页面与目录 API 的 HTTP 检查通过；详见 `docs/local-test-2026-09-29.md`。
- 浏览器曾检查到新增表单和控件，并定位出 SunCalc 版本适配错误；修正后回归测试通过。最终浏览器复查被“管理员策略无法验证”的安全检查阻断，不能据此宣称端到端交互或最终三维画面已验收。
