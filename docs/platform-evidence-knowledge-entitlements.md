# 摄影证据、知识关系与授权交付试点

更新：2026-10-23。本迭代把原有照片 EXIF、山脊候选、摄影知识和余额交易接到可追溯的内部链路；它不是外部支付、版权确权或真实视觉定位的上线证明。

## 运行与迁移

使用 Node 22。对已有数据库先运行 `npm run db:backup`，再运行 `npm run db:migrate`。旧缩略图运行 `npm run images:privatize-thumbnails` 移出静态目录；新的上传直接写入 `data/thumbnails/`。`/uploads/*` 由代理拒绝，图片只能经授权接口读取。`npm run kg:seed` 幂等地导入六个带来源的编辑建议节点和四条关系。原始照片、私有缩略图、数据库备份不进入 Git。

迁移**不会**给旧作品自动授予分发许可。作者在作品详情的“照片证据与授权”里提交范围，管理员分别审核作品与许可。缺少任一审批、提交新许可待审或撤权后，作品从公开列表、原图与缩略图接口、相框清单中退出；作者仍能从“我的作品”查看和修改自己的作品。迁移前应先在测试数据库执行完整迁移与回归，再切换生产实例。

## 契约与流程

| 入口 | 行为与权限 |
| --- | --- |
| `GET /api/resources/media/photos/{id}` | `MediaCard v1`；作者/管理员看私有详情，公开用户只看已审批且网页许可有效的卡；精确坐标依作者的独立分享选择。Schema 在 `contracts/media-card.v1.schema.json`。 |
| `GET/PATCH /api/photos/{id}/evidence` | 仅作者/管理员读取字段证据和候选；作者确认或排除候选时新增不可混淆的人工记录，确认不等于现场精度核验。 |
| `POST /api/photos/{id}/skyline-candidates` | 作者使用指定区域和人工山脊标记搜索低可信度候选；保存 DEM 卡片版本、误差与证据，不自动改写作品机位。普通上传分析仍是 `exif_only`。 |
| `GET/POST/DELETE /api/photos/{id}/license` | 作者查看、提交新版本或撤销作品许可。新申请从 `pending` 开始；不同终端、收费、下载与再加工分别声明。 |
| `GET /api/admin/licenses`、`PATCH /api/admin/licenses/{id}` | 管理员查看并审批/拒绝当前许可版本；内容审核不自动批准许可。 |
| `GET /api/knowledge?q=...` | 仅返回已发布、带来源的节点及两端也已发布的关系。管理端节点/关系创建 API 要求来源 URL 和 claim 类型。 |
| `GET /api/entitlements/me`、`GET /api/frame/manifest` | 登录用户查看权益和相框播放清单；每次交付重新交叉检查购买权益与当前来源许可。许可撤销后已有购买记录保留审计，但不继续下发画面。 |

原图和缩略图均经 `/api/photos/{id}/image`、`/thumbnail` 授权。相框清单仅使用已经购买且获得相框收费授权的照片，`channel=frame` 只接受相框权益；网页解锁不自动变成相框权益。`frame_content_bundles` 在展示和下单时重新检查每张照片的相框授权，订单事务内再检一次，防止撤权期间交付。

购买权益绑定审核通过的许可版本。撤权或提交新版许可后，旧权益不会自动恢复；旧版本的网页解锁记录可由本人在新版获批后重新点击“解锁”免费补领当前版本的网页权益。此操作不补领相框权益。

## 当前明确边界

- 视觉定位只有人工标记山脊的限定区域候选；OCR、地物检索、多模态模型和 ControlNet 概念图尚无可调用模型、合法参考素材与真值评测，不能标成已完成。EXIF 缺 GPS 时不推断精确坐标。
- 知识种子是 QuasarFrame 编辑建议，`claimType=recommendation`；地理、历史、人文事实需要逐条来源、许可、核验时间和编辑审核后才可发布。当前没有事实级内容库。
- 摄像头分发继续受 `AUTHORIZED_FEED_IDS` 默认关闭；源方二次分发授权、采集/接收时间和可接受延迟仍未确定，本迭代不启用新摄像头交付。
- 现有余额扣款可供本地软件试点；微信/支付宝验签回调、退款结算、税务、真实设备绑定和硬件型号尚未完成。相框清单目前以登录用户会话模拟软件终端。
- 作者授权勾选是工作流记录，不替代权属证明或正式法律条款。真实收费/跨屏发布前还需制定许可文本、核验原始权利和支付合规流程。

验证：`npm test`、`npm run typecheck`、`npm run lint`、`npm run build`，以及公开知识、未授权作品、静态缩略图和未登录权益的 HTTP 烟测。用户作品真值与外部授权仍需单独现场验收。
